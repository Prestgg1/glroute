# glroute

Lightweight parallel LLM router for Gleam — priority fallback and true parallel fan-out over `gdantic_ai`.

[![Gleam](https://img.shields.io/badge/gleam-1.14-ffaff3)](https://gleam.run)
[![Erlang](https://img.shields.io/badge/target-erlang-red)](https://www.erlang.org)
[![Gleam Test](https://github.com/Prestgg1/glroute/actions/workflows/test.yml/badge.svg)](https://github.com/Prestgg1/glroute/actions/workflows/test.yml)

> **AI Disclosure:** This project was **entirely written by AI** and was created for my own personal purposes — to experiment with a production-ready parallel request router on top of `gdantic_ai` and to use it as a building block in other personal projects. All code, tests, and documentation were generated by AI and reviewed by me.

Built on [`gdantic_ai`](https://github.com/Prestgg1/gdantic_ai) — PydanticAI-inspired typed agent library for Gleam. While [OmniRoute](https://github.com/diegosouzapw/OmniRoute) is a sequential fallback proxy (tries providers one-by-one), `glroute` adds **true parallel execution** via Erlang processes.

```sh
gleam add glroute
```

## Why glroute?

[OmniRoute](https://github.com/diegosouzapw/OmniRoute) (`v3.8.49`) is a powerful unified AI gateway — 290 providers, 19 combo strategies, RTK+Caveman compression — but its routing is **sequential**: `for (orderedTargets) await executeTarget()`. If the first provider is slow, every request waits. The only parallel path is the specialized `fusion` strategy (panel + judge synthesis).

`glroute` is the missing piece:

- **`Priority` (sequential fallback)** — like OmniRoute combos: try agents in order, return the first success. Simple, reliable.
- **`Parallel` (true fan-out)** — run **all** agents **concurrently** via Erlang `process.spawn + Subject`, collect every result in ~one latency instead of N. This is the core difference.
- **Production-ready, small** — `List(Agent(deps, output))` API, typed output via `glon`, mockable HTTP, ready to harden later (timeouts, circuit breaker, rate limiting).

## Features

- **Priority routing** — sequential, first-success fallback
- **Parallel routing** — concurrent fan-out with `gleam/erlang/process` (Erlang scheduler, not `Promise.all` in JS)
- **Typed** — `Agent(deps, output)` + `glon.JsonSchema(output)` — schema + decoder stay in sync
- **Any provider** — reuses `gdantic_ai` providers: `OpenAI`, `Gemini`, `OpenAICompatible` (Ollama, OpenRouter, Together, Groq, Azure...)
- **Tested** — 15 tests with mocked HTTP, including a timing test proving parallelism (<250ms for 3×100ms vs 300ms sequential)

## Quick Start

### Priority (sequential fallback)

Like OmniRoute — tries in order, skips failures:

```gleam
import gdantic_ai/agent
import gdantic_ai/provider
import glon
import glroute

pub type City { City(city: String, country: String) }

let schema = {
  use city <- glon.field("city", glon.string())
  use country <- glon.field("country", glon.string())
  glon.success(City(city:, country:))
}

let agents = [
  agent.new(provider.openai("gpt-4o", "sk-...")) |> agent.with_glon(schema),
  agent.new(provider.gemini("gemini-2.5-flash", "AIza...")) |> agent.with_glon(schema),
  agent.new(provider.openai_compatible("llama3", "http://localhost:11434/v1", "ollama"))
    |> agent.with_glon(schema),
]

// Tries a1 → a2 → a3, returns first Ok
case glroute.route_priority(agents, "Which country is Paris in?", Nil) {
  Ok(result) -> echo result.output  // City("Paris", "France")
  Error(e) -> echo e
}
```

### Parallel (true concurrent fan-out)

The key feature OmniRoute lacks — all agents run at once:

```gleam
let result = glroute.route_parallel(agents, "Which country is Paris in?", Nil)

echo result.ok_count     // 2
echo result.error_count  // 1
// result.results: List(TargetResult(City)) — sorted by original priority index
case result.results {
  [first, second, ..] -> echo first.result  // Ok(City(...)) or Error(...)
  _ -> Nil
}
```

With timeout:

```gleam
let result = glroute.route_parallel_with_timeout(agents, "test", Nil, 10_000)
```

**Timing:** 3 agents × 100ms sleep → parallel finishes in ~100-120ms, sequential would be ~300ms. Verified in `parallel_is_actually_parallel_test`.

### Plain text (no schema)

```gleam
let agents = [
  agent.new(provider.openai("gpt-4o", "sk-...")),
  agent.new(provider.openai("gpt-4o-mini", "sk-...")),
]
let result = glroute.route_parallel(agents, "Say hello", Nil)
// Each TargetResult(String) contains "Hello world" or similar
```

## Architecture

```
glroute/
├── src/glroute/
│   ├── route.gleam      # Strategy, TargetResult, ParallelResult, PriorityResult
│   └── parallel.gleam   # route_priority (loop) + route_parallel (spawn + Subject)
├── src/glroute.gleam    # Public API: route_priority, route_parallel, route_parallel_with_timeout
└── uses gdantic_ai/
    ├── provider.gleam   # OpenAI / Gemini / OpenAICompatible
    ├── agent.gleam      # Agent(deps, output) + with_glon + run
    └── http.gleam       # Mockable HttpClient
```

```
Priority:  agent1 ──fail──► agent2 ──ok──► return
                \ sequential, no concurrency

Parallel:  agent1 ─┐
           agent2 ─┼─► spawn_unlinked + Subject ─► collect (Selector-like) ─► ParallelResult
           agent3 ─┘   Erlang scheduler, timeout per target
```

## API

```gleam
// Priority: List(Agent) -> Result(RunResult, GdanticError)
pub fn route_priority(
  agents: List(Agent(deps, output)),
  prompt: String,
  deps: deps,
) -> Result(RunResult(output), GdanticError)

// Parallel: List(Agent) -> ParallelResult (always returns, even if all fail)
pub fn route_parallel(
  agents: List(Agent(deps, output)),
  prompt: String,
  deps: deps,
) -> ParallelResult(output)

pub fn route_parallel_with_timeout(
  agents: List(Agent(deps, output)),
  prompt: String,
  deps: deps,
  timeout_ms: Int,
) -> ParallelResult(output)

pub type TargetResult(output) {
  TargetResult(index: Int, model: String, result: Result(RunResult(output), GdanticError))
}
pub type ParallelResult(output) {
  ParallelResult(results: List(TargetResult(output)), ok_count: Int, error_count: Int)
}
```

## Comparison

| Feature | OmniRoute | glroute |
|---|---|---|
| Routing | Sequential fallback (1-at-a-time) | **Both**: Priority sequential **and** Parallel fan-out |
| Parallel | Only `fusion` (panel+judge) | **Any** `List(Agent)` in parallel via Erlang processes |
| Language | Node.js | Gleam (Erlang/OTP) |
| Scope | 290 providers, gateway, compression | Small, focused, production-usable router |
| Typed output | No (JS) | Yes (`glon` schema + decoder) |
